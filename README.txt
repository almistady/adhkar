رفع الملفات على GitHub من الجوال:
1) افتح مستودع adhkar ثم اضغط "uploading an existing file" (في المربع الأزرق Quick setup).
2) اضغط choose your files واختر "Choose Files" ثم حدّد كل الملفات السبعة من تطبيق الملفات.
3) انتظر انتهاء الرفع ثم Commit changes.
4) Settings > Pages > Deploy from a branch > main > / (root) > Save.
5) بعد دقيقة يظهر الرابط: https://اسم-حسابك.github.io/adhkar/
